# Interactive Portfolio

A personal portfolio built as an interactive desktop-style experience rather than a traditional portfolio website.

The idea was to make the site feel closer to exploring a small digital world than scrolling through a list of projects.

## What is this?

The portfolio is built around a game-like interface called **NEXUS**.

You can move through different areas, open windows, explore projects, check my profile and skills, play small games, and gradually unlock more of the portfolio through an XP-based progression system.

It still works like a normal portfolio underneath it, so you can get to the important stuff without having to solve a puzzle just to find my GitHub.

## Main sections

### Profile

A game-style character profile showing:

- Skills and their levels
- Technical strengths
- Work experience
- Current progression
- Character attributes

### Archive

Projects are presented as interactive case files instead of static cards.

Each project includes information about the stack, role, implementation and relevant links.

### Playground

A collection of small browser games and interaction experiments.

The games are intentionally short and simple, more like little distractions than full games. They are there to make the portfolio feel interactive and give visitors something to explore.

### Comms

A contact section for getting in touch directly.

### Terminal

A small simulated terminal with portfolio-related commands and information.

## Desktop interactions

The interface supports a few desktop-like interactions:

- Drag windows around the screen
- Minimize and restore windows
- Maximize windows
- Close windows
- Snap windows to the left or right side
- Open multiple windows at the same time
- Switch between light, dark and system themes

## Progression

The site uses a small XP system.

Some interactions unlock XP once rather than rewarding repeated clicks, so the progression is based on actually exploring the portfolio.

As areas are discovered, more of the project archive becomes available.

## Tech

Built with:

- React
- Vite
- JavaScript
- CSS
- CSS animations and transitions

The project is intentionally kept fairly lightweight instead of relying on a large collection of UI libraries.
